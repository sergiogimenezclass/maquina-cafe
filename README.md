# Máquina de café

Ejemplo didáctico de una máquina expendedora de café para estudiantes de Diseño Web.

## Primera etapa

La interfaz está construida únicamente con HTML y CSS:

- CSS Grid organiza las zonas principales.
- Flexbox ordena los componentes internos.
- Los colores están escritos directamente, sin variables CSS.
- Las medidas utilizan píxeles y porcentajes.
- El código contiene comentarios didácticos.
- Los controles todavía no tienen JavaScript.

Para verla, abrí `index.html` en el navegador.

Las funcionalidades se incorporarán gradualmente mediante commits independientes.
